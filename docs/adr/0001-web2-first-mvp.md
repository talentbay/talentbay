# ADR-0001: Web2-First MVP

Date: 2026-06-09
Status: Accepted

## Context

TalentBay DMCC materials include Web3, token, and pre-ICO narratives, but the current codebase does not contain Web3 product functionality. The practical first product needs to be usable before token mechanics are introduced.

## Decision

Build the first MVP as a Web2 SaaS/job board:

- Vacancies.
- Candidate profiles.
- Company/admin workflows.
- Relocation calculator.
- Applications.

Web3, KYC, payments, custody, token transactions, and smart contracts are out of scope for the first MVP.

## Consequences

- Engineering focuses on core product value.
- Legal/compliance risk is reduced during MVP development.
- Pre-ICO materials must be separated from core product behavior and approved by founder/legal.
