# Design Direction

Last updated: 2026-07-23

## Design Source

Figma file:

<https://www.figma.com/design/Rt0QPhEy7k9fAa9ZCuSCHP/Untitled>

Implemented direction:

- Product-first information architecture.
- Heritage navy/teal brand palette.
- Manrope typography.
- Compact operational UI rather than a marketing landing page.
- Vacancy and relocation information visible in one workflow.

The Figma file contains foundations, reusable controls, vacancy cards, responsive headers and three page directions:

- Heritage.
- Product-first.
- Recommended composition.

The recommended composition is the implementation reference.

## Product Principles

- The first viewport shows the job-search product.
- Vacancy data, source status and relocation estimates are distinguishable as verified or demo.
- Mobile layouts preserve search, scan and apply workflows.
- Controls use Nuxt UI primitives and Lucide icons.
- English is the first language; copy and layout should remain ready for i18n.

## Design Review Rule

Substantial new user flows should be represented in Figma before or alongside implementation. Minor states and corrections may be implemented directly when they conform to the existing component language.
